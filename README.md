# Student Grade

- Create a `Student` class with name and marks.
- Calculate student grades using `getGrade()`.
- Display Pass/Fail status.
- Use `filter()` to find passing students.
- Use `map()` to get the names of passing students.
- Use `reduce()` to calculate the class average.
- Use `sort()` to find the highest scorer.
- Use destructuring to get the top student.
- Use a ternary operator for Pass/Fail.
